# Get

My own version of the `find` and `grep` utilities merged into one tool, used to quickly *get* a file or directory containing a pattern either in its filename or content.

This "fork" obviously doesn't have the same capabilities as the two tools mentionned above, my goal is only to make it support my most commonly used options.

This is a side-project of a beginner in C so it is obviously kind of ugly I think.
